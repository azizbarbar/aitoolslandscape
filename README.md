AI Tools Landscape is a desktop experimental atlas: 58 workflow profiles across five categories, including 14 Multi-Model Platforms.
Double-click index.html for offline use, or start-server.bat to install Node.js if needed and open a local preview; stop-server.bat stops it. Select a tool and choose Lock on to keep a dotted reference; locking a new selection replaces it. In Balanced map, the solid selection controls the animated gradient and the largest quadrant receives a stronger tint.
Edit scores.json using method.md, run node prepare-data.cjs to update geometry, roster and browser data, then node check.cjs to validate.
Sources: the workshop matrix, user-requested additions, official product documentation and recorded editorial assumptions.
Profiles are interpretive, not benchmarks; DeepSeek is estimated, Sora is historical/discontinued, and some local brand marks are typographic redraws.
