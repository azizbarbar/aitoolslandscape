AI Tools Landscape is a desktop experimental atlas: 58 workflow profiles across five categories, including 14 Multi-Model Platforms.
Double-click index.html for offline use, or start-server.bat to install Node.js if needed and open a local preview; stop-server.bat stops it.
Select a tool, then hover or focus its row and choose Lock on to keep it as a dotted reference. Other selections stay solid; locking the new selection replaces the previous lock. Unlock releases the reference. Both views and saved URLs preserve the comparison.
Edit scores.json using method.md, run node prepare-data.cjs to update geometry, roster and browser data, then node check.cjs to validate.
Sources: the workshop matrix, user-requested additions, official product documentation and recorded editorial assumptions, checked October 15, 2026.
