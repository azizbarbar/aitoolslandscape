## Midjourney

Inventive image exploration with a precise foothold in masked editing and layered composition.

Scope: Paid Midjourney web image creation, V8.2 and its documented Edit Model / Editor; excludes experimental Thinking Mode and video.

Limit: Unmasked regions can stay unchanged, but generated details and reference identities are not exact guarantees.

- [Midjourney Version](https://docs.midjourney.com/hc/en-us/articles/32199405667853-Version)
- [Midjourney Edit Model](https://docs.midjourney.com/hc/en-us/articles/48495453462797-Edit-Model)
- [Midjourney Editor](https://docs.midjourney.com/hc/en-us/articles/32764383466893-Editor)

## NotebookLM / Gemini Notebook

A reading set becomes a grounded conversation and a family of source-derived formats.

Scope: Standalone web notebook: selected-source chat and Studio reports; base access with plan-dependent limits. Experimental agentic actions excluded.

Limit: Source grounding does not guarantee interpretation; experimental code and file agents are outside this profile.

- [Learn about Gemini Notebook](https://support.google.com/gemininotebook/answer/16164461)
- [Use chat in Gemini Notebook](https://support.google.com/gemininotebook/answer/16179559?hl=en)
- [Generate reports in Gemini Notebook](https://support.google.com/gemininotebook/answer/18323649?hl=en)

## Elicit

Evidence is organized into editable study fields, with room to refine the research protocol.

Scope: Elicit Pro systematic review, search, extraction and reports; excludes Enterprise-scale limits and Scale-only figure extraction.

Limit: Audit generated screening and extraction decisions; a structured workflow is not comprehensive literature coverage.

- [Elicit systematic literature reviews](https://elicit.com/solutions/systematic-review)
- [Elicit pricing](https://elicit.com/pricing)

## Claude Code

Broad software invention, with a strong upper-right reach for specified edits checked against code and tests.

Scope: Coding agent with repository files, command execution, diffs and tests; suitable paid account or API access.

Limit: Tests verify selected properties, not every requirement; no automatic CAD or pixel-preservation claim.

- [Claude Code overview](https://code.claude.com/docs/en/overview)
- [Claude Code common workflows](https://code.claude.com/docs/en/common-workflows)

## Claude

Broad invention with a strong directed-writing shoulder; source-bound proposals are narrower than free exploration.

Scope: Claude web/desktop chat with projects, documents, code execution and web search; Free or paid within limits. Excludes Research, Design and Claude Code workflows.

Limit: Local edits and executable files are inspectable, but prose preservation and citations still require human checking.
